TOPIC: Functions, parameters and return statements

1. Functions: 
	- Functions are reusable blocks of code designed to perform a particular task. They help in organizing code, reducing repetition, and enhancing readability.

	- syntax of function:
		function functionName(parameters) {
			// Function body
			// Perform operations
			return value;    // optional
		}
	
	
2. Function Parameters:
	- Parameters are placeholders defined in the function declaration. They act as variables that can hold values passed to the function when it is called.
	
	example:
		function greet(name) {    // this name is a `parameter`
			console.log(`Hello, ${name}!`);
		}
		greet("Alice");   // this Alice is an `argument`
		// Output: Hello, Alice! 

	- Default Parameters:
		- Functions can have default parameter values that are used if no argument is provided.
		
		example:
			function greet(name = "Guest") {
				console.log(`Welcome, ${name}!`);
			}
			greet();          // Output: Welcome, Guest!
			greet("Charlie"); // Output: Welcome, Charlie!
			
		
3. Return Statement:
	- The return statement is used to send a value back to the caller of the function. If no return is specified, the function returns undefined.
	
	example: 
		function add(a, b) {
			return a + b; 		// Returns the sum
		}
		const result = add(5, 10); 		// result is 15
		console.log(result); 			// Output: 15
		

4. Function Types:
	1. Function Declaration
	2. Function Expression
	3. Arrow Functions
	4. Anonymous Function
	5. Immediately Invoked Function Expression (IIFE):
	
	1. Function Declaration:
		- These are functions defined using the function keyword.
			function sum(x, y) {
				return x + y;
			}
			console.log(sum(4, 2)); 		// Output: 6

	2. Function Expression:
		- Functions can also be assigned to a variable.
			const multiply = function (a, b) {
				return a * b;
			};
			console.log(multiply(3, 5)); 	// Output: 15
			
	3. Arrow Functions:
		- A concise way to write functions, introduced in ES6.
			const sum = (a, b) => a + b;
			console.log(sum(10, 2)); 	// Output: 12
			
	4. Anonymous Function:
		- An anonymous function is a function that does not have a name. These functions are often used when the function does not need to be reused or referenced elsewhere.
		
		example: 
			const greet = function() {
				console.log("Hello, World!");
			};
			greet(); // Output: Hello, World!
			
		example2:
			// anonymous function using arrow function
			setTimeout(()=>{
				console.log("This runs after 2 seconds!");
			}, 2000);

	4. Immediately Invoked Function Expression (IIFE):
		- This is an IIFE (Immediately Invoked Function Expression), where the anonymous function is executed immediately after it's defined.
		
		example: 
			(function() {
				console.log("This function runs immediately!");
			})();
